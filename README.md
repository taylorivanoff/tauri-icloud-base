# tauri-icloud-base

Shared Tauri 2 shell for iCloud / Apple web wrappers - Safari UA, Windows font fix, Apple cookie persistence, tray, cloudos toolbar strip, and on Windows a Spotify-minimal frameless titlebar (refresh / min / max / close + drag).

Depends on [`tauri-tray-base`](https://github.com/taylorivanoff/tauri-tray-base).
